# Personal CV Website

A simple personal CV website built with HTML5, showcasing education, skills, and contact information.

## 📋 Features

- Personal information section with profile picture
- Educational background and grades
- Skills rating system using star emojis
- Contact form with email integration
- Responsive design support
- Two-page structure (main + contact)

## 🛠️ Technologies Used

- HTML5
- Form handling
- Unicode emojis
- Responsive meta tags

## 🎯 Project Structure

```
.
├── index.html          # Main CV page
├── contact.html        # Contact form page
├── Vinoth.jpg         # Profile picture
├── LICENSE            # GNU GPL v3 license
└── README.md          # Project documentation
```

## 📝 Usage

1. Clone the repository
2. Open `index.html` in your web browser
3. Navigate through the CV using the provided links

## 📧 Contact Form

The contact form allows visitors to:

- Enter their name
- Provide their email
- Write a message
- Submit directly to the specified email address
